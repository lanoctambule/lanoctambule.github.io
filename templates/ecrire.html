Première connexion

Pour publier, cette page a besoin d'une clé d'accès GitHub (à créer une seule fois, voir le guide ci-dessous). Elle reste uniquement sur cet appareil.

Comment créer la clé d'accès (2 minutes, une seule fois)
  1. Sur github.com, connecte-toi, clique sur ta photo en haut à droite, puis Settings.
  2. Tout en bas du menu de gauche : Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Donne-lui un nom (ex. « Écrire sur le blog ») et choisis une durée (1 an au maximum).
  4. Dans Repository access, choisis Only select repositories et sélectionne uniquement le dépôt du blog.
  5. Dans Permissions → Repository permissions, mets Contents sur Read and write. Ne touche à rien d'autre.
  6. Clique sur Generate token, copie la clé (elle commence par github_pat_) et colle-la dans le champ ci-dessus. GitHub ne la montre qu'une fois.

Cette clé ne donne accès qu'à ce blog. Si tu perds ton téléphone, supprime-la depuis la même page de GitHub.
